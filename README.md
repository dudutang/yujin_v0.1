# 余烬 · Embers

像素风末日生存游戏原型：提着灯走进灰潮，割草出征 + 避难所（工坊）循环。纯 HTML5 Canvas，没有外部素材——像素画、光照、音乐和音效都由代码实时生成。

**直接玩：** 用浏览器打开 `dist/index.html`。

## 两个职业

- **弧光师**：每次升级一位**灯魂**来访（雷、焰、霜、光、蚀、时，外加命运），三张卡全是她/他的；一局最多结缘三位。70 张祝福分 7 种槽位（普攻改造、提灯、击发、施放、威能、召唤、被动），另有 7 张传奇。按 <kbd>Q</kbd> 换一位灯魂，<kbd>R</kbd> 重随。
- **破障者**：一把消防斧，可换攻击方式和斧刃效果，8 级在誓约碑前转职（守灯骑士 / 狂战士 / 黑暗骑士）。

## 设计原则

- 靠构筑取胜，不靠操作：没有闪避键，不做弹幕。
- **灰潮浓度是唯一的计时器**：一直在涨，离灯塔越远涨得越快；修好的路灯能压住它。
- 每张卡写明具体数字，以及哪些词条会影响它。
- 世界没有边：灯塔在中心，往任何方向走，越远越深。

## 目录

| 路径 | 内容 |
| --- | --- |
| `src/js/` | 游戏代码，按 `ORDER.txt` 的顺序拼在一起（共享同一个脚本作用域） |
| `src/style.css`、`src/shell.html` | 界面样式和页面骨架 |
| `dist/index.html` | 构建产物，单个文件，可以直接打开 |
| `tools/build.js` | 构建：拼接模块 + 语法检查 |
| `tools/sim.js` | bot 快进模拟若干局，打印存活、等级、反应次数 |
| `tools/shots.js` | 自动截图：标题、升级面板、战斗、全图、暂停 |

主要模块：`12_arc_gods.js`（灯魂与祝福）、`13_gear.js`（装备）、`14_world_map.js`（无限地图）、`15_warrior.js`（破障者）、`10_damage.js`（伤害、状态与元素反应）、`23_cards.js`（升级卡与稀有度词条）、`27_render.js`（渲染与光照）、`30_audio.js`（声音）。

## 开发

```sh
npm install
npx playwright install chromium   # 只在第一次需要
npm run build    # src → dist/index.html
npm test         # 构建 + 两个职业各跑 4 局 bot
npm run shots    # 构建 + 截图到 shots/
```

改代码只改 `src/` 下的文件，然后 `npm run build`。

存档只在浏览器的 localStorage 里（工坊科技、录音带、装备）。
